# LanBall

Suunnitelma ja päätösloki: `docs/SUUNNITELMA.md` ([G] Valtterin päätös, [E] ehdotus, [A] auki).

## Git-käytäntö (sovittu 23.9.2026, päivitetty samana päivänä)

- Työ tehdään `main`-haarassa. Erillinen haara vain kokeiluille, jotka kannattaa pitää erillään.
- Commit aina, kun päätös tai siivun osa on valmis.
- Repo: julkinen `Valttern/LanBall` (https://github.com/Valttern/LanBall).
- Tuotanto on GitHub Pages (https://valttern.github.io/LanBall/): jokainen push `main`iin ajaa testit ja julkaisee pelin. Push on siis julkaisu, ja se kysytään ennen.
- Repo tunnistautuu Valttern-tilillä omalla `.git/config`-asetuksellaan. Koneen oletustili pysyy `kalaherkut`, eikä `gh auth switch` ole tarpeen.
